# claude-plugins

Brandon Seaver's Claude Code plugins. The repository is also the marketplace,
so one URL installs everything:

```text
/plugin marketplace add <this repository's git URL>
/plugin install <plugin>@brndnsvr
```

## Plugins

- [adhd-mode](plugins/adhd-mode/) — one item at a time, one decision per
  reply, a status line on every reply. On by default in every session;
  `/adhd-mode off` turns it off.
